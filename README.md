# BLADE & CO. — Barbearia Modern & System

Sistema web completo de agendamento e gestão para a **Barbearia Blade**, desenvolvido com foco em alta performance, experiência de usuário fluida e design monocromático minimalista.

---

## Destaques do Projeto

- **Design Premium Monocromático**: Paleta em preto e branco com tipografia de alto impacto (`Playfair Display`, `Bebas Neue` e `Inter`).
- **Animações Fluidas & Microinterações**: Transições suaves e elementos dinâmicos criados com **Framer Motion** e estilos customizados em CSS Keyframes (marquee, barber pole, ruído sutil de fundo).
- **Sistema Integrado de Agendamento**: Agendamento intuitivo em 3 etapas com validação visual e verificação de horários disponíveis.
- **Painel Administrativo Completo**: Gestão em tempo real de agendamentos, métricas do dia, receita estimada e controle de status.
- **Arquitetura Full-Stack**: API desenvolvida nativamente com **Next.js App Router** com suporte a **MongoDB** e mecanismo de armazenamento resiliente em memória como fallback.

---

##  Páginas e Funcionalidades

1. **` / ` — Landing Page Principal**
   - Hero Section com tipografia de destaque e chamadas dinâmicas.
   - Apresentação da barbearia, lista de serviços com valores e durações.
   - Avaliações de clientes, galeria e rodapé de contatos rápidos.

2. **` /agendamento ` — Fluxo de Agendamento**
   - **Passo 1**: Seleção do serviço desejado (Corte, Barba, Combo, Pigmentação).
   - **Passo 2**: Seleção interativa de data e horário disponível.
   - **Passo 3**: Confirmação dos dados do cliente e envio direto para a API e confirmação no WhatsApp.

3. **` /admin ` — Dashboard Administrativo**
   - Visualização de todos os agendamentos registrados.
   - Métricas em tempo real (Total de agendamentos, confirmados, concluídos e faturamento).
   - Filtros rápidos por data e busca por nome ou serviço.
